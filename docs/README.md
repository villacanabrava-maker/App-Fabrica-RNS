## A decisão que governa tudo

```
FASE 1   O aplicativo funciona          (agentes simulados, custo zero)
FASE 2   Os agentes são reais           (OpenAI + Claude, revisão dupla)
FASE 3   A fábrica refina a si mesma    (o visual é feito pela própria fábrica)
```

1. O humano é a autoridade final. Nenhum modelo aprova.
2. GitHub é a verdade do software.
3. Supabase é a verdade da operação.
4. O Orchestrator é determinístico. Modelos sugerem; ele decide.
5. Evidência antes de afirmação.
